Documentation opérationnelle - Stages de pré-rentrée Mathématiques 2026-2027

Ce paquet contient la déclinaison opérationnelle des quatre programmes validés : entrée en Quatrième, Troisième, Seconde générale et technologique, et Première générale spécialité mathématiques.

Formats

  • Markdown (.md) : source éditable et versionnable.
  • HTML (.html) : version A4 directement imprimable depuis un navigateur.
  • PDF initiaux : tests de positionnement originaux et bilans nominatifs fournis.

Arborescence d’un niveau

  • 00_MASTER : document maître et index.
  • 01_ENSEIGNANT : guide du formateur et tableau de bord.
  • 02_SEANCES/S1...S5 : fiche professeur, fiche élève, supports et cartes d’aide.
  • 03_EVALUATIONS : test initial, mini-diagnostic, évaluation finale et portfolio.
  • 04_NOMINATIFS : dossiers individuels et remédiations ciblées.
  • 05_SOURCES : programme validé et documents sources copiés.

Impression

  1. Ouvrir le fichier HTML souhaité.
  2. Choisir Imprimer puis format A4, échelle 100 %, arrière-plans graphiques activés.
  3. Pour les fiches élèves, imprimer en recto simple afin de conserver les espaces de réponse.
  4. Pour les cartes d’aide et supports, utiliser du papier épais lorsque possible.

Confidentialité

Les répertoires 04_NOMINATIFS contiennent des données personnelles de mineurs. Ils doivent rester dans le circuit Nexus Réussite et être transmis uniquement à la famille concernée.

Source de vérité

Les quatre fichiers stage_prerentree_*.md fournis constituent la base pédagogique unique. Les documents générés n’en modifient ni l’ordre des séances, ni les objectifs, ni les diagnostics ; ils les transforment en supports utilisables.
