## Plan d’action validé dans le programme source

## 9.4 Fares Laajili

Fares possède un socle solide dans six domaines, mais présente trois conceptions particulièrement nettes : multiplication erronée des fractions, usage arithmétique direct des côtés dans Pythagore et confusion entre cosinus et sinus. 

| Élément               | Plan                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------- |
| **Priorité 1**        | Multiplier correctement deux fractions                                                                  |
| **Priorité 2**        | Reconstruire Pythagore à partir des carrés                                                              |
| **Priorité 3**        | Distinguer cosinus et sinus                                                                             |
| **Points d’appui**    | Relatifs, puissances, calcul littéral, équations, proportionnalité, statistiques                        |
| **Remédiations**      | Conflit cognitif, représentation d’aire, carrés géométriques, changement d’angle de référence           |
| **Indicateurs**       | 5 produits de fractions ; 3 problèmes de Pythagore ; identification correcte des rapports sur 4 figures |
| **Approfondissement** | Division de fractions, réciproque, Thalès, sinus, tangente, fonctions                                   |
| **Conseil Troisième** | Ne pas confondre rapidité et validation : contrôler la structure avant d’appliquer une règle            |
| **Après le stage**    | Un problème de transfert par semaine et réactivation espacée des trois erreurs initiales                |
