# Démarrage rapide

1. Générer le paquet : `make all`.
2. Ouvrir `dist/site-public/index.html` directement, ou lancer `make serve` puis ouvrir `http://localhost:8000`.
3. Imprimer un PDF dans `dist/pdf/` ou un pack dans `dist/packs/`.
4. Pour retrouver un élève, ouvrir uniquement `dist/site-private/suivi-nominatif.html` puis son dossier privé correspondant.

Ne placez jamais un PDF ou un lien issu de `nominatifs-prives` dans le site public.
