## 3. Décision pédagogique

Le stage ne doit pas lui imposer une reprise lente de notions déjà connues. Le parcours vise :

- fiabilité du code ;
- tests et cas limites ;
- autonomie ;
- explication orale ;
- gestion du temps ;
- transformation d’une spécification en programme.

## 6. Conseils pour le parcours candidat individuel

- programmer en temps limité sur de petits sujets ;
- verbaliser la spécification avant de coder ;
- utiliser systématiquement des assertions ;
- relire les bornes de `range` ;
- distinguer la taille d’une structure et ses indices ;
- expliquer une fonction en termes d’entrées, sorties et cas limites ;
- conserver une preuve de chaque exercice exécuté.
