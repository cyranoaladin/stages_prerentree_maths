# Avant le premier jour

- ☐ imprimer `08_PACKS_PDF/1re_nsi_PACK_ELEVE_COMPLET.pdf` en recto simple ;
- ☐ conserver le pack enseignant hors de la vue des élèves ;
- ☐ imprimer séparément les deux dossiers nominatifs ;
- ☐ installer Python 3.11+ et Thonny sur les deux postes ;
- ☐ décompresser le pack de code commun et le pack personnel de chaque élève ;
- ☐ ne jamais copier `1re_nsi_CODE_ENSEIGNANT.zip` sur un poste élève ;
- ☐ vérifier l’ouverture de `mesures_capteurs.csv` ;
- ☐ créer un dossier de sauvegarde pour chaque élève ;
- ☐ ouvrir le tableau de bord enseignant ;
- ☐ reporter les objectifs individuels.

# Répartition des parcours

| Élève | Parcours | Principe |
|---|---|---|
| Ahmad BELDI | Fondations guidées | traçage obligatoire, code à compléter, feedback fréquent et retrait progressif des aides |
| Ahmed BENHADJ SALEM | Fiabilisation et autonomie | débogage, cas limites, contrats, tests, justification et QCM chronométré |

> Les fiches communes ne portent aucun nom. Le parcours est indiqué dans le dossier nominatif et par l’enseignant.

# Préparer chaque séance

| Séance | Fichier Python | Support principal | Production attendue |
|---:|---|---|---|
| 1 | `s1_variables_conditions_starter.py` | tables de trace et boîtes mémoire | premier programme interactif commenté |
| 2 | `s2_boucles_starter.py` | cartes `range`, compteur et accumulateur | outils d’analyse d’une liste |
| 3 | `s3_fonctions_tests_starter.py` | cartes paramètre/argument/retour | fonctions documentées avec assertions |
| 4 | `s4_structures_csv_starter.py` | cartes listes/dictionnaires/CSV | chargement et traitement de données capteurs |
| 5 | `projet_final_starter_ahmad.py` ou cahier des charges Ahmed | tris, dichotomie et grille de tests | mini-projet final testé et présenté |

# Routine des 120 minutes

1. rituel et prédiction ;
2. apport théorique bref ;
3. traçage papier ;
4. programmation ;
5. tests et débogage ;
6. différenciation ;
7. jalon du projet ;
8. exit ticket.

# Contrôles de fin de séance

- ☐ le code élève est sauvegardé et versionné ;
- ☐ le corrigé est resté séparé ;
- ☐ l’aide maximale a été consignée ;
- ☐ au moins un test normal et un cas limite ont été exécutés ;
- ☐ l’élève a expliqué une erreur ;
- ☐ le tableau de bord est mis à jour ;
- ☐ le travail à reprendre avant la séance suivante est explicite.
