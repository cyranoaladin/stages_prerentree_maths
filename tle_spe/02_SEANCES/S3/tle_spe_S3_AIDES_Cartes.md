# Terminale Spécialité Mathématiques — Séance 3 — Cartes d'aide
## Second degré et signe du trinôme

---

### Carte A — Rappel de propriété

> Δ = b² − 4ac.
> Δ > 0 : deux racines (−b ± √Δ)/(2a). Δ = 0 : racine double −b/(2a). Δ < 0 : aucune racine.
> Contrôle : somme = −b/a, produit = c/a.
> Signe : du signe de a à l'extérieur des racines, du signe contraire entre les racines.

---

### Carte B — Première étape faite

> Pour −2x² + 8x − 6 :
> on peut factoriser par −2 : −2(x² − 4x + 3).
> Les racines de x² − 4x + 3 sont **1 et 3**.
>
> À toi : quel est le signe de a ? Où le trinôme est-il positif ?

---

### Carte C — Exemple résolu à transposer

> **Exemple.** Sur quel intervalle −x² + 4x − 3 est-il strictement positif ?
> Δ = 16 − 12 = 4, √Δ = 2. Racines : (−4 + 2)/(−2) = 1 et (−4 − 2)/(−2) = 3.
> Ici **a = −1 < 0** : le trinôme est négatif à l'extérieur des racines, positif entre elles.
>
> | | −∞ | | 1 | | 3 | | +∞ |
> |---|---|---|---|---|---|---|---|
> | signe | | − | 0 | + | 0 | − | |
>
> Réponse : le trinôme est strictement positif sur ]1 ; 3[.
> **Contrôle** en x = 2 : −4 + 8 − 3 = 1 > 0 ✓
>
> **À toi de transposer**, en gardant les quatre étapes : Δ, racines, signe de a, contrôle.

---

### Carte D — Découpage en quatre questions

> 1. Calcule Δ et donne son signe.
> 2. Si Δ ≥ 0, calcule les racines et contrôle-les par la somme et le produit.
> 3. Note le signe de a, puis remplis le tableau de signes.
> 4. Traduis le tableau en ensemble solution, en choisissant les bons crochets.

## Carte « contrôle » — à utiliser avant toute certitude de 4

> - J'ai vérifié mes racines par la somme (−b/a) et le produit (c/a).
> - J'ai regardé le signe de a **avant** de remplir mon tableau.
> - J'ai testé une valeur dans chaque zone de mon tableau.
> - Mes crochets correspondent au type d'inégalité (stricte ou large).

---

## Carte « erreurs fréquentes » — à distribuer en fin de séance

> 1. Appliquer « du signe de a à l'extérieur » sans regarder a : c'est l'erreur la plus
>    coûteuse du chapitre.
> 2. Oublier le cas Δ < 0 : le trinôme garde alors le signe de a partout.
> 3. Donner les racines quand on demande un ensemble solution d'inéquation.
> 4. Oublier le symbole ∪ entre deux intervalles.
> 5. Écrire Δ = b² + 4ac.
