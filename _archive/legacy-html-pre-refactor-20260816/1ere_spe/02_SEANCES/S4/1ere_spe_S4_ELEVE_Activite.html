Ma trace écrite

Trace écrite attendue

Une hausse de (t%) correspond au coefficient :

[ 1+.]

Une baisse de (t%) correspond au coefficient :

[ 1-.]

Pour deux événements (A) et (B) :

[ P(AB) ==========

P(A)+P(B)-P(AB). ]

[ P(A)=1-P(A).]

Introduction :

[ P_A(B)= P(A).]
