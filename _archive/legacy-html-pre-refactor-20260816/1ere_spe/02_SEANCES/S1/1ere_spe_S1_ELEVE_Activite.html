Activité de départ

Activité 2 — « Trois formes, trois usages »

À partir de :

[ P(x)=x^2-6x+5,]

faire obtenir :

[ P(x)=x^2-6x+5,]

[ P(x)=(x-1)(x-5),]

[ P(x)=(x-3)^2-4.]

Question :

Quelle forme choisir pour calculer, trouver les zéros ou repérer le minimum ?
