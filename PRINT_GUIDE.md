# Guide d’impression

- Imprimer les fiches élèves en recto simple, A4, échelle 100 %, marges par défaut et arrière-plans activés.
- Imprimer les supports et cartes sur papier 120 g/m² si possible ; couper sur les pointillés après impression.
- Les supports à code couleur doivent rester lisibles en noir et blanc grâce aux libellés et contours.
- Assembler les packs par niveau ou séance depuis `dist/packs/`; vérifier le nom de l’élève avant toute remise nominative.
